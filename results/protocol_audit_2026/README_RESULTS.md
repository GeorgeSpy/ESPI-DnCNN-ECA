# Protocol V2 public audit summary

This directory contains compact, non-sensitive summaries of the protocol,
manifest, target-validity, physical-provenance, and training-pilot decisions.
It is documentary evidence, not a release of the private corpus or the full
machine-specific experiment tree.

- `v2a_split_sizes.csv`: leakage-safe V2-A sizes.
- `v2b_fold_sizes.csv`: held-out-board V2-B sizes.
- `protocol_decision_registry.csv`: final revision-level outcomes.
- `target_and_observable_decisions.csv`: H1/H2/H3/H4 boundaries.
- `training_pilot_outcomes.csv`: frozen early-pilot outcomes and interpretation.

See [`docs/PROTOCOL_V2_AUDIT_STATUS_2026.md`](../../docs/PROTOCOL_V2_AUDIT_STATUS_2026.md)
for the scientific boundary.
